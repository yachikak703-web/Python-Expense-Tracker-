# Personal Expense Tracker (Python)

A beginner-friendly command-line project to record and manage daily expenses.

## Features
- Add expenses with title, category, amount, and date
- View all saved expenses
- See total spending and category-wise summary
- Delete an expense by its ID
- Export expenses to a CSV file for Excel
- Automatically saves data in `expenses.json`

## Requirements
- Python 3.8 or newer
- No external Python packages required

## How to run
1. Download or clone this repository.
2. Open a terminal in the project folder.
3. Run:

```bash
python expense_tracker.py
```

On some Windows systems, use `py expense_tracker.py`.
